# CEJM — Viser le 10

Application de révision CEJM pour BTS SIO. PWA installable, 4 modes de jeu, répétition espacée SM-2.

## Lancer en local
npm install
npm run dev

## Build
npm run build

## Déployer sur GitHub Pages
npm run deploy

> Prérequis : le dépôt GitHub doit s'appeler `CEJM-final`.
> L'app sera accessible sur https://<username>.github.io/CEJM-final/
